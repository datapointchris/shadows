# Shadows Documentation

Shadows tracks personal files that live inside a work repository without committing them there.
This directory holds the command reference, the architecture write-up, the roadmap, and the Go
material the project is taught through.

## Documentation

- [Development Guide](DEVELOPMENT.md) — Toolchain prerequisites, first build, the test and debug loop, and fixes for the errors that come up early
- [Quick Reference](QUICK_REFERENCE.md) — Cheat sheet of Go, Cobra, SQLite and git commands used daily, with the project's own conventions at the end
- [api/](api/index.md) — Command reference
- [architecture/](architecture/index.md) — How Shadows works, and what is planned
- [learning/](learning/index.md) — Go material written against this codebase
